App readiness report

Hudumika SMS.

What is working, what remains, and the exact gates for enabling the SMS application in production.

Audit date · 17 September 2026
Decision

Conditional — not yet production-ready

The core SMS product is implemented and its two serious security/compliance defects were fixed. Production release still depends on mandatory webhook-secret configuration, provider certification, delivery lifecycle testing, compliance review and dedicated regression coverage.

5release gates

Critical configuration warning

SMS_WEBHOOK_SECRET must be set in production.
The webhook authentication hook deliberately skips validation when the value is absent. An unset secret would reopen the forged inbound-message and fake opt-out vulnerability fixed under HUD-0125.

Pending work

Release blocker

Secure webhook configuration

Generate and deploy a strong SMS webhook secret, place it in the secret manager, append the token to every provider callback URL and verify requests without it receive HTTP 401.

Release blocker

Provider certification

Test Africa's Talking and Twilio using production-like credentials, approved sender IDs, funded accounts and publicly reachable callback URLs.

High priority

Delivery lifecycle

Verify queued, sent, delivered, failed and undelivered states, including duplicate callbacks, out-of-order callbacks, unknown IDs and provider retries.

High priority

Campaign and worker reliability

Exercise scheduled campaigns, Redis downtime, worker restarts, partial bulk failures, multi-gateway failover and duplicate-delivery prevention.

High priority

Compliance sign-off

Validate consent evidence, STOP handling, opt-out imports/removals, supported-country phone normalization, retention and applicable messaging regulations.

High priority

Automated regression tests

Add SMS-specific tests for webhook tokens, forged requests, tenant isolation, opt-outs, phone formats, campaign retries and gateway fallback.

Operational

Monitoring and alerts

Monitor failed and undelivered rates, rejected webhooks, stuck campaigns, provider balance, gateway health, worker backlog and retry exhaustion.

Operational

Runbooks and key rotation

Document provider outage response, webhook-secret rotation, sender-ID changes, opt-out disputes, credential replacement and campaign cancellation.

Production release checklist

Set and rotate SMS_WEBHOOK_SECRET; prove all four webhook routes reject missing and incorrect tokens.
Send real messages through both supported providers and receive authentic delivery and inbound callbacks.
Run scheduled and bulk campaigns through restart, retry, failover and partial-failure scenarios without duplicate delivery.
Obtain compliance approval for consent, opt-out, retention and country-specific sending rules.
Add automated regression coverage, monitoring dashboards, alerts and an operator runbook.
