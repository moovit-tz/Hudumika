# Workflows & State Modeling

## Status Lifecycle
1. `IDEA` (Triage)
2. `BACKLOG` (Unplanned)
3. `PLANNED` (Scheduled for upcoming cycle)
4. `IN_PROGRESS` (Actively being worked on)
5. `IN_REVIEW` (PR open, awaiting review)
6. `TESTING` (QA/Verification)
7. `DONE` (Merged/Completed)
8. `RELEASED` (Deployed to production)

## Terminal States
- `REJECTED`, `DUPLICATE`, `CANCELLED`, `WONT_FIX`
