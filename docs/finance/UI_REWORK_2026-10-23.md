# FinOps UI rework — 23 October 2026

## Reference review
Reviewed the supplied MiniMart screenshots and live demo: back-office navigation, POS mode switch, customer register search, product ascending/descending sorting, and printer/drawer preferences. Reference font was not adopted. Hudumika typography, configured semantic colours, component variants and branding remain authoritative.

## Implemented
- Dedicated full-viewport POS replaces back-office header/sidebar; POS entry in header and F1 shortcut; Back office exits the till.
- Category rail on desktop, horizontal category navigation on mobile; grid/list catalogue; product search; distinct Products/Current sale panes on phones.
- Consolidated secondary till actions in More (printer settings, register history, held carts when present, cash movement and register open/close).
- Browser/account/tenant-scoped printer preferences for 58mm, 80mm and A4, auto print, customer visibility and receipt footer; isolated receipt print document with escaped data and subtotal/discount/tax/payment/change detail.
- Shared search-first register layout in invoices, credit notes, payments, products, vendors, bills and purchase orders. Invoice date presets and From/To pickers replace duplicate date controls.
- Shared DataTable keyboard sorting, numeric sort accessors, pagination and row-action event isolation; multi-line vendor identity/contact rows with existing actions retained.
- Customer directory search, name/trade/date/status sorting and shared page-size/pagination controls.
- Compact two-column FinOps mobile metrics; wrapping filters and actions; updated live component catalog and design-system documentation.

## Design-system compliance pass

- **CustomerDirectoryPage.tsx:** Replaced 14 `var(--card-bg, var(--white))` with `hsl(var(--card))`; migrated ActionsMenu from native `<button className="dd-item">` to `DropdownMenuItem`/`DropdownMenuSeparator`; replaced native view-toggle and clear buttons with `Button variant="ghost" size="xs"`.
- **FinanceVendors.tsx:** Replaced ~12 native `<input style={inp}>` with `Input`, native `<textarea>` with `Textarea`, legacy `.btn-primary`/`.btn-secondary` with `Button`/`Button variant="outline"`; removed hardcoded `color="#fff"` on icon; deleted unused `inp`/`sel` style objects.
- **FinancePos.css:** Changed `.pos-category-nav` background from `var(--white)` to `hsl(var(--card))` for dark-mode correctness; added `@media(min-width:1200px)` rule to surface toolbar shift stats and keyboard-shortcut hints on wide desktop (matching reference POS pattern).
- **FinancePos.tsx:** Replaced 5 inline-styled `<Link>` elements in register history dialog with `Button variant="ghost" size="xs" asChild` wrapping `<Link>`.
- **PurchaseOrders.tsx:** Replaced view-toggle `background: var(--teal); color: '#fff'` with `hsl(var(--primary))`/`hsl(var(--primary-foreground))`; same fix on pagination active-page button.

## Limits
No sales, payments, register closing or supplier/customer mutations were performed. This is UI verification, not a repeat of the accounting integration suite or a production sign-off. Local bills dataset was empty, so populated bill-detail journeys were not verified. Physical printer output, direct ESC/POS printing and cash-drawer pulses were not verified; drawer integration is explicitly shown as not connected. Reference inventory modules such as FEFO/batch expiry, label generation and scale hardware were reference context, not newly fabricated integrations or modules.

## Global design-system expansion (second pass)

Added platform-wide CSS utility classes and tokens to `index.css`, all controlled from the design system:

### New `:root` tokens

| Token | Default | Purpose |
|---|---|---|
| `--ds-cell-px` | 14px | Horizontal cell padding (tables + settings) |
| `--ds-th-py` | 10px | Table header vertical padding |
| `--ds-th-fs` | 10.5px | Table header font size |
| `--detail-sidebar-w` | 340px | Detail-page sidebar width |
| `--detail-gap` | 20px | Detail-page grid gap |

### New global utility classes

- **`.detail-layout`** / `.detail-main` / `.detail-sidebar` — two-column main+sticky-sidebar grid for record-detail pages (PO, Bill, Invoice). Collapses to single column at ≤960px.
- **`.detail-fields`** / `.detail-field-label` / `.detail-field-value` / `.detail-field-sub` — horizontal info-field row (SUPPLIER, SOURCE, SHIP TO).
- **`.sidebar-card`** / `.sidebar-card-title` / `.sidebar-card-body` — sidebar summary panels (Totals, Timeline, Notes).
- **`.sidebar-total-row`** (+ `.is-primary`, `.is-balance`) — summary/totals rows inside sidebar cards.
- **`.detail-timeline`** / `.detail-timeline-item` / `.detail-timeline-dot` / `.detail-timeline-content` — vertical dot-line history.
- **`.settings-table`** / `.settings-name` / `.settings-desc` — configuration/preferences table (Printer Settings, Tax Config).
- **`.ds-empty-state`** / `.ds-empty-state-icon` — canonical centered empty state with icon + heading + description + action.
- **`.date-preset-bar`** / `.date-preset-pill` (+ `.is-active`) — date filter preset pills (All/Today/7 days/30 days/This month).
- **`.ds-status-row`** / `.ds-status-step` (+ `.is-done`, `.is-current`) / `.ds-status-connector` — inline status progress indicator.
- **`.ds-record-thumb`** (+ `.is-placeholder`) — product/record image thumbnail (extends DataTable's `.ds-record-cell`).
- **`.ledger-table`** / `.ledger-qty-in` / `.ledger-qty-out` — dense stock-activity/GL-journal read-only log.

### Updated existing rules

- `.rtbl th` and `.rtbl td` now read `--ds-cell-px` and `--ds-th-py` / `--ds-th-fs` tokens (previously hardcoded `9px 13px`).
- Added `.rtbl th:last-child, .rtbl td:last-child` right-padding rule for uniform table gutters.
- All new classes have dark-mode overrides in the `[data-theme="dark"]` block.
- `docs/DESIGN_SYSTEM.md` token contract table and new sections updated.
