Brand marks

The Hudumika wordmark and glyph. Files live in apps/web/public/.

FileUse
logo-light.svg / .pngWordmark for light grounds
logo-dark.svg / .pngWordmark for dark grounds
hudumika-icon.svgGlyph only — square contexts, avatars, tight spaces
favicon.svg / favicon.pngBrowser tab

Rule

Never recolour a wordmark to match a ground. Swap the file. The pair is switched by CSS that already exists in index.css — give both images the classes below and the correct one survives:

<img src="/logo-light.svg" class="logo-light-only" alt="Hudumika">
<img src="/logo-dark.svg"  class="logo-dark-only"  alt="Hudumika">

Both are in the DOM; display:none hides the wrong one per html[data-theme='dark']. That is deliberate — it means the swap costs no request and cannot flash during a theme change.

components/PoweredByHudumika.tsx is the ready-made component for the attribution lockup. Use it rather than placing the wordmark by hand.

App logos

20 apps in the launcher. Each is a 40×40 mark on an rx="11" rounded square in the app's own colour.

Defined but outside the launcher

Reference

An app's colour is its identity, not the platform brand. These stay fixed when a tenant changes their theme — --teal does not apply here. A tenant may upload a replacement per app through Branding, which overrides the vector mark at runtime.

Using a mark

Always through the component. It handles the fallbacks you will otherwise forget.

import { LauncherAppSvg, LAUNCHER_APPS } from '@/components/LauncherApps';

<LauncherAppSvg id="clearos" color="#ea580c" size={52} />
<LauncherAppSvg id={app.id} color={app.color} logoUrl={tenantLogo} />
  • logoUrl takes precedence, for a tenant's own upload.
  • A broken or deleted upload falls back to the vector mark — never the browser's broken-image glyph.
  • An unknown id renders a neutral placeholder rather than an empty square.
  • Corner radius scales with size (size × 0.275), so a mark stays proportionate at 24px and at 96px.

Icon set

168 stroke-only icons on a 24×24 grid, in components/Icon.tsx. Hover any tile for its name.

<Icon name="shipment" size={16} color="var(--teal)" />

Trap

Icon names are a literal union, not string. That is load-bearing: before it was typed this way, 26 misspelled names across the app compiled cleanly and rendered nothing at all, invisibly. If a name does not exist, add the path to Icon.tsx — do not widen the type or fall back to an inline SVG.

Rule

  • Stroke only, no fill. Default stroke weight comes from the iconStrokeWidth design token, so do not hardcode one unless the icon genuinely needs to differ.
  • Colour via currentColor or a token — never a literal hex.
  • Wrap an icon that carries meaning on its own in FeaturedIcon, which supplies the tinted container and the semantic variant.
