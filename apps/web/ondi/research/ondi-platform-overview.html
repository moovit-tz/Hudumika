04 — Trust Engine & Score Model
The Multidimensional Trust Graph
The Ondi Trust Score (0–850) is not a credit bureau score. It is a portable, multidimensional trust graph — combining six categories of signals into a single portable assertion of trustworthiness that any participant in the ecosystem can consume (with user consent).
⚡ Trust Score Thresholds
Score ≥ 700 — Frictionless access. No step-up MFA. Fast-lane loan processing. Preferred onboarding tier.
Score 500–699 — Standard access. Step-up MFA on sensitive actions. Conditional loan eligibility.
Score < 500 — Heightened review. Manual KYC escalation. Restricted access permissions. Fraud watchlist check.

Multi-tenant architecture with permissioned data layers per actor type.
RBAC enforced at the API gateway — roles from INDIVIDUAL to PLATFORM_ADMIN.
All internal services communicate via mTLS; external clients via OAuth 2.0 PKCE.
Every trust signal consumed by a third party is user-consent-gated. No passive data monetisation.

09 — Shared Platform Infrastructure
Common Foundation — Built for East Africa
Shared services that every Ondi module runs on — no duplication, maximum consistency. Hosted on Contabo infrastructure (Frankfurt & Nuremberg), chosen for cost-efficiency, East Africa latency performance, and GDPR-equivalent data governance at ~8× lower cost than AWS.
🖥 Contabo Hosting Architecture
Primary Cluster: Contabo VPS XL / Dedicated Servers — Frankfurt (DE) data centre. GDPR-compliant, ISO 27001-certified. Latency to Dar es Salaam: ~130ms; Nairobi: ~120ms — acceptable for API-first architecture with Cloudflare edge caching.

Deployment Stack: Docker + Kubernetes (K3s) on Contabo bare-metal VPS. Nginx reverse proxy. PostgreSQL (primary) + Redis (cache / queue). MinIO for object storage (biometric hashes, credential vault, audit logs).

Backup & Redundancy: Contabo Object Storage for automated daily backups. Geo-redundant replica in Nuremberg (DE). 99.9% uptime SLA. Failover via HAProxy + keepalived.

Cost Advantage: Contabo dedicated server (128GB RAM, 8 cores, 1.6TB NVMe) ≈ €89/month vs AWS r6i.4xlarge ≈ $700+/month — approximately 8× cost saving. Critical for East Africa pricing tiers.
